Core Values

우리가 지키는 원칙

VAL-01

Zero Human-in-the-loop

사람의 손이 닿는 순간 그건 자동화가 아닙니다. 끝까지 자율로 동작하는 시스템을 만듭니다.

VAL-02

Build, Break, Repeat

논문보다 프로토타입이 먼저. 직접 만들고, 부수고, 다시 만들면서 배웁니다.

VAL-03

Open by Default

코드, 데이터, 실패 기록까지 공개합니다. 우리 연구가 다른 연구의 출발점이 되도록.
